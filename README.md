# Release Drill

Sandbox for the release-process onboarding drill.

Use this repository to practice the full issue → branch → pull request ritual for a release:

1. Open an issue describing the change.
2. Create a branch off `main`.
3. Commit your changes on the branch.
4. Open a pull request (start it as a draft).
5. Link the pull request to the issue it resolves, then mark it ready for review.
