# Release Notes Checklist

- [ ] Confirm version number and changelog entry are up to date before tagging.
- [ ] Run the full test suite locally and verify no regressions.
- [ ] Review the diff against main and ensure all generator artifacts are committed.
- [ ] Obtain sign-off from the release reviewer and record it in this checklist.
- [ ] Green-light the production deploy; verify the deployed artifact matches the tag.
