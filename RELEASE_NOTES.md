# Release Checklist

Short release checklist for the release-process onboarding drill.

- [ ] Verify build passes on the default branch
- [ ] Review RELEASE_NOTES.md for the release checklist entries
- [ ] Cut a `drill/notes` branch and open a PR from it
- [ ] Leave a reviewer comment on the PR before merging
- [ ] Merge the PR and confirm the commit SHA on `main`
